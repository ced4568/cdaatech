# CDAA Technologies Logo Package

The approved identity is the modular holding-company mark. Four independent
units form one engineered system around a protected central core.

## Primary assets

- `cdaa-logo-light.svg` — full-color horizontal logo for white/light backgrounds
- `cdaa-logo-dark.svg` — full-color horizontal logo for navy/dark backgrounds
- `cdaa-logo-one-color.svg` — one-color logo for print, engraving, and restricted production
- `cdaa-logo-white.svg` — white one-color logo for dark production surfaces
- `cdaa-mark.svg` — icon-only master for favicons, avatars, and small placements
- `cdaa-mark-white.svg` — white icon-only mark for dark production surfaces
- `*-1600.png` — transparent high-resolution raster exports
- `cdaa-mark-1024.png` and `cdaa-mark-512.png` — transparent icon exports
- `apple-touch-icon.png`, `favicon-32.png`, and `favicon.ico` — browser/device assets

## Brand colors

- Navy: `#0F172A`
- Blue: `#2563EB`
- Orange: `#F97316`
- White: `#FFFFFF`

## Usage

Keep clear space around the logo equal to at least one quarter of the mark's
height. Do not stretch, rotate, recolor, add effects, or place the light logo
on a dark background. Use the icon-only mark below 140 px of available width.

The SVG files are the production masters. Use PNG only where SVG is unsupported.
